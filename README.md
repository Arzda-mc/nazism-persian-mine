# وب‌سایت حزب آلمان | پرشین ماین

## فایل‌هایی که باید در ریشه مخزن آپلود کنی
همه فایل‌ها را کنار `index.html` قرار بده. برای تصویر جدید سرور، فایل تصویر را دقیقاً با نام `server.jpg` ذخیره و آپلود کن:

| نام دقیق فایل | کاربرد |
|---|---|
| `clan.jpg` | تصویر پروفایل کلن |
| `server.jpg` | تصویر پروفایل سرور پرشین ماین |
| `leader.jpg` | تصویر پروفایل رهبر |
| `Arzda.jpg` | تصویر کوچک طراح در پایین سایت |
| `music.mp3` | موسیقی پس‌زمینه |

نام فایل‌ها را دقیقاً با همین حروف بنویس.

## پیوندها
- کانال اصلی پرشین ماین: `https://rubika.ir/joinc/EHCBGIGI0BCJFEPUMOQIXHTHXUJASCXT`
- گروه اصلی کلن: `https://rubika.ir/joing/%2BBACEDFHCJ0BKQUMNACDBFEGTPLYWTICY`

در لینک گروه، علامت `+` ابتدای کد دعوت به صورت `%2B` نوشته شده تا در نشانی وب به‌عنوان بخشی از مسیر حفظ شود. با این حال، اگر خود روبیکا برای این لینک صفحه وب عمومی ارائه نکند، مرورگر ممکن است همچنان خطای ۴۰۴ نشان دهد. بازشدن مستقیم در برنامه فقط وقتی ممکن است که نسخه اندروید روبیکا این پیوند را به‌عنوان App Link بپذیرد؛ وب‌سایت نمی‌تواند این رفتار را به‌اجبار تضمین کند.

## انتشار
1. ZIP را استخراج کن.
2. تمام فایل‌های داخل آن را در ریشه Repository آپلود کن.
3. در GitHub به Settings → Pages برو.
4. Deploy from a branch، شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.
5. سایت را یک بار با اینترنت باز کن تا فایل‌ها در مرورگر ذخیره شوند.


صفحه `ranks.html` شامل فهرست مقامات و اعضایی است که نامشان در پیام ارسالی مشخص شده بود. موارد «تعیین نشده» عمداً خالی از نام عضو باقی مانده‌اند.
